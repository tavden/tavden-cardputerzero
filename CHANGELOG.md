# Changelog

## 0.1.0 — 2026-09-04

Initial pre-hardware proof of concept:

- Tavden-branded 320 × 170 overview and keyboard navigation;
- System module for host, architecture, uptime, memory, storage and load;
- passive Network module for local interface, IPv4 and RX/TX state;
- light/dark theme persistence and native-resolution screenshots;
- desktop simulator build and system snapshot test;
- deterministic privacy-safe demo data for public screenshots;
- official-template AArch64 cross-build and arm64 Debian packaging;
- AppBuilder/store metadata with no optional permissions;
- explicit upstream provenance, licensing and hardware validation plan.

Physical CardputerZero compatibility remains untested in this release.
